# NOC Syslog Inteligente

Aplicación web tipo NOC para recibir, clasificar y gestionar eventos Syslog de equipos Cisco, Fortinet y Huawei, con política de defensa frente a agentes de IA. Hecha con HTML, CSS y JavaScript.

## Cómo abrirla
Doble clic en `index.html` (Chrome, Edge o Firefox).

La documentación de planeación está en la carpeta `docs/`.
